🛍️ Pickup orders

This guide shares general information about common grocery-order questions. Available options depend on the retailer, order status, location, and current policy.

Pickup options depend on the retailer and order.

Steps to consider

  1. Check the pickup date and time in the order confirmation.
  2. Read the retailer’s official arrival instructions before leaving.
  3. Review messages about substitutions or unavailable items.
  4. If you need to change a pickup, check the options in the official app or website.
  5. Use official support for order-specific help.

For account-specific questions

For order-specific questions, use Kroger’s official website or app. This site provides general information only.
