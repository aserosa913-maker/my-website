INDEPENDENT INFORMATION GUIDE

👤 Account and sign-in

This guide shares general information about common grocery-order questions. Available options depend on the retailer, order status, location, and current policy.

This website cannot access, unlock, or reset retailer accounts.

Steps to consider

  1. Confirm you are using the correct email address or username.
  2. Use the password-reset process on the retailer’s official website or app.
  3. Check that you are visiting the genuine website before entering credentials.
  4. Never share a password or one-time verification code with anyone.
  5. If access remains unavailable, use the provider’s official account-recovery process.

For account-specific questions

For order-specific questions, use Kroger’s official website or app. This site provides general information only.
