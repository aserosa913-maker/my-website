DOORDASH + KROGER ON ONE DOMAIN (SEPARATE PAGES)

This bundle keeps the DoorDash information guide at the domain root and places the separate Kroger order-information guide in the /kroger/ folder.

Expected URL structure after uploading the contents to your hosting document root:
- https://YOURDOMAIN.com/             DoorDash information guide
- https://YOURDOMAIN.com/privacy-policy.html
- https://YOURDOMAIN.com/kroger/      Kroger order and tracking information guide
- Kroger guide pages and privacy policy are inside /kroger/ and its subfolders.

UPLOAD INSTRUCTIONS
1. Back up the current website files first.
2. Upload the contents of this ZIP to the same hosting document root as the current DoorDash site, preserving folders and paths.
3. Do not upload the enclosing ZIP folder as an extra nested directory. The root index.html should remain at the domain root and the kroger folder should sit beside it.
4. The DoorDash homepage footer now has a link to /kroger/.
5. If your host uses a public_html or www directory, upload the contents there.

IMPORTANT
- Both sites will use the same domain but separate URL paths; a single domain cannot serve two different homepage files at the same root URL simultaneously.
- The DoorDash page remains an independent guide. The Kroger page is also labeled as independent information. Keep those disclosures visible and do not imply official affiliation or that the listed assistance phone number is an official brand number.
